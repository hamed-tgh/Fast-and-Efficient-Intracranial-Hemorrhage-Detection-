# Abstract

Intracranial hemorrhage (ICH) is a neurological disease which if not detected in brain computed tomography (CT) scans at its early stage, it can be highly deadly. to detect it we proposed a framework is evaluated on the RSNA Intracranial Hemorrhage Detection dataset in multi-label classification setting. 
Experimental results on the validation set depict a strong performance, such as achieving an AUROC of 0.983 along with micro- and macro-averaged F1-scores and high sensitivity for the clinically important “any hemorrhage” class.
